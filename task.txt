LAMPIRAN — RANGKUMAN ENDPOINT (INTI)
============================================================
Auth
- POST /auth/login → JWT + profil (guru: id, nip, full_name)
- GET  /auth/me → profil berjalan dari token

Students (admin untuk tulis)
- GET  /students?class_id=&search=
- GET  /students/:id
- POST /students
- PUT  /students/:id
- DELETE /students/:id

Classes (BARU)
- GET  /classes
- GET  /classes/:id
- GET  /classes/:id/students

Attendance (teacher/admin)
- GET  /attendance/teacher/:teacherId/today
- GET  /attendance/schedule/:scheduleId?date=YYYY-MM-DD
- POST /attendance/record

Reports (teacher/admin)
- GET  /reports/class/:classId?month=&year=
- GET  /reports/export?classId=&month=&year=

AI (opsional, setelah aggregator siap)
- GET  /ai/alerts?classId=&month=&year=
